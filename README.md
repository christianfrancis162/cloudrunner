Cloudrunner is a 3D arcade flight game set in a golden-hour alpine valley: take off from a mountain airfield, thread a low-poly stunt plane through 8 glowing rings, manage fuel and airframe damage, and land back on the runway for the touchdown bonus.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — fly with WASD / arrow keys, Shift and Ctrl for throttle, mouse to steer, Space for the airbrake.
